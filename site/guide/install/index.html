Install

A Windows installer or one Linux AppImage. Either takes a couple of minutes.

Download for Windows Linux AppImage

Windows 10/11 (64-bit) · Linux x86_64

Windows

  1. Download Horazon-Setup-version.exe and run it.
  2. Windows SmartScreen may say "Windows protected your PC", because the installer isn't code-signed. Click More info → Run anyway.
  3. Allow the administrator prompt. The installer sets up the game capture once, so you won't see that prompt again when you play (why it needs admin).
  4. Horazon starts and puts its portal in the system tray. Closing the window keeps it running there.

Linux

One AppImage works on any distro. Download it, make it executable and run it:

chmod +x Horazon-*.AppImage

Updates replace the file in place, with no root needed. For a menu entry, use a tool like AM or Gear Lever, or your desktop's own AppImage integration.

Game capture needs python3, setcap (libcap) and pkexec (polkit); most desktops already have all three. The run tracker above the game uses xprop on KDE.

Before you play: Horazon reads the game's network traffic. PD2's rules forbid third-party software that interacts with the game, so you use it at your own risk. Is this allowed?
