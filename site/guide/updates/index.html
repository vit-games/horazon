Updates and your data

Updates arrive on their own, and none of them can touch what you have recorded.

Updates

Horazon checks GitHub for a new version at start and every few hours, and downloads it in the background. When it is ready, a banner and a notification offer Restart and update. If you ignore them, it installs the next time you quit.

Automatic checks can be turned off in the tray menu (Check for updates automatically).

Where your data lives

Outside the app, in %APPDATA%\Horazon on Windows or ~/.config/Horazon on Linux. Installing, updating or uninstalling never touches it. The tray menu opens the folder (Open data folder).

Backups

  • One every day, on its own.
  • One before every update is installed, and again before a new version changes the database layout.
  • One whenever you ask: tray → Back up now.

Restore any of them from Setup → Backups. An older version refuses to open data that a newer one has already upgraded, so it can't damage it.

Moving to a new PC

Setup → Backups → download a backup, install Horazon on the new PC, import the file there and restore it.
