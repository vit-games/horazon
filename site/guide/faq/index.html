FAQ

How it works, whether it is allowed, and what to do when something isn't recording.

How does it see my drops? Does it touch the game?

It never touches the game. Horazon reads the network traffic between your PC and the PD2 game server, the same data the game itself receives, and decodes item drops, area changes and kills from it. Nothing is injected, no game memory is read and nothing is sent to the server. Reading network traffic needs extra rights, which is why there is a one-time admin prompt. Your stash and characters are confirmed through PD2's public API.

Why don't my kills match .kills?

They should. Horazon counts every monster it sees die in your game, whoever killed it, the way .kills does, and leaves out what .kills leaves out: summons, traps and monster-cast hydras. Games Horazon didn't record (capture off, or joined before capture started) aren't counted. To check, type .kills at the start and end of one game: the difference should equal the game's kills on the Session page. If it doesn't, report it in Issues with the time of the game.

Is this allowed by PD2?

Project Diablo 2's rules forbid third-party software that interacts with the game. Horazon doesn't interact with the game or its files, but that is a judgement call. Use it at your own risk, and check the current rules yourself. Horazon isn't affiliated with or endorsed by Project Diablo 2 or Blizzard.

Does anything leave my PC?

Requests go to PD2's own API and site (your stash and characters, the season list, and item art the app doesn't ship) and to GitHub, where the app checks for a new version; the tray menu can turn that check off. There is no telemetry and no Horazon server.

Is it safe to paste my PD2 token?

The token is your login to the PD2 website, so treat it like a password and paste it only into Horazon. Horazon uses it to read your shared stash from PD2's API and stores it in the database on your PC, nowhere else. Without it everything still works, except that items stashed right after pickup are never seen and stashed uniques and sets are missing from the grail.

Capture says "Needs permission" or shows an error

Linux: Setup → Game connection → Grant permission again (or the same item in the tray menu). A system Python upgrade breaks the private copy.
Windows: use the tray item, which re-registers the capture task. If drops still don't show up, check that the Windows Firewall rule Horazon Capture exists and that a VPN isn't carrying the game traffic.

A game I was already in wasn't recorded

A game is recognised from its first packets, so capture has to be running before you join. With Start and stop capture with the game on, that happens when the game starts.

I can't find the tray icon

GNOME shows tray icons only with an extension such as AppIndicator and KStatusNotifierItem Support. Capture permission can also be granted on the Setup page, under Game connection.

Port 8080 is already in use

Change "port" in config.json in the data folder (tray → Open data folder) and restart Horazon. Overlay addresses use the new port.

How do I move to a new PC?

Setup → Backups → download a backup, install Horazon on the new PC, import the file there and restore it.
